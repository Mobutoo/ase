# Ase — Human-Centric Flow Engine

Ase is a human-oriented productivity app combining adaptive focus sessions,
energy tracking, shared calendars and ambient music.
Forked from [PomoTracker](https://github.com/viodid/PomoTracker) (MIT).

## Stack

- Python 3.12, Django 5.2 LTS, Django REST Framework, PostgreSQL 16
- Uvicorn ASGI, Channels, Redis and Celery
- React 18, TypeScript, Vite, Tailwind; Node.js 24 LTS

## Local development

Use PostgreSQL (the models include PostgreSQL array fields) and Redis.

```bash
python -m venv .venv
. .venv/bin/activate
pip install -r requirements.lock
export DEBUG=1 DB_HOST=localhost DB_NAME=ase DB_USER=ase DB_PASSWORD=your-local-password
python manage.py migrate
python manage.py collectstatic --noinput
uvicorn ase_project.asgi:application --host 127.0.0.1 --port 8000 --reload
```

In another terminal:

```bash
cd frontend
npm ci
npm run dev
```

Django reads environment variables, not `.env` files. Docker Compose loads `.env`.
Never enable `DEBUG=1` on an exposed server.

## Checks

```bash
DB_PASSWORD=your-local-password python manage.py test --settings=ase_project.test_settings --noinput
python manage.py makemigrations --check --dry-run --settings=ase_project.test_settings
pip install pip-audit
pip-audit -r requirements.lock
cd frontend
npm test
npm run build
npm audit
```

Tests need a PostgreSQL user allowed to create test databases. Test settings replace
Redis, email and Channels with in-memory services and disable external agents.
CI runs these checks for pull requests and pushes to `main`.

## Deployment and upgrades

Read [maintenance and migration instructions](docs/MAINTENANCE.md) before upgrading,
particularly the OIDC account bindings, session reset and integration allowlists.
Copy `.env.example` to `.env`, fill in fresh secrets, then use
`docker compose -f docker-compose.preprod.yml up --build -d`.
The checked-in preproduction domain must be adapted for your deployment.
Build assets are generated by CI/Docker and are not versioned.
